# ClientBridge Nigeria 🇳🇬
> **Your Skills Deserve Customers** — Verified Artisans & Tech Experts Marketplace across 36 Nigerian States & FCT.

ClientBridge is a fast, modern web application connecting vetted Nigerian professionals (electricians, fashion designers, graphic artists, web developers, caterers, photographers, and more) with clients nationwide.

---

## 🌟 Key Features

- **36 Nigerian States + FCT Filter**: Seamless local search across Lagos, Abuja, Port Harcourt, Kano, Enugu, Ibadan, and all 36 states.
- **15 Service Categories**: Tech, creative arts, bespoke tailoring, home repairs, baking, catering, and wellness.
- **Direct WhatsApp Messaging**: 1-click verified WhatsApp outreach with pre-filled enquiry messages formatted for Nigerian country code (`+234`).
- **Naira Pricing Transparency**: Transparent upfront pricing with formatted Naira (`₦`) starting fees.
- **Interactive Naira Quote Calculator**: Estimate project costs based on service tier, location, and turnaround urgency.
- **Dual Role Dashboards**:
  - **Provider Dashboard**: Edit profile photo, manage portfolio gallery, customize service package pricing, and track leads.
  - **Client Dashboard**: Manage profile avatar, review saved artisan bookmarks, and view WhatsApp contact history.
- **Client-Side Image Compression**: Automatic canvas image compression for instant avatar and portfolio photo uploads.
- **SEO & Social Share Ready**: Complete OpenGraph, Twitter card metadata, and Schema.org `WebApplication` structured data.

## 🚀 One-Click Free Deployment (Vercel / Netlify)

### Deploy on Vercel:
1. Go to [vercel.com](https://vercel.com) and click **"Continue with GitHub"**.
2. Click **"Add New Project"** and select **`ClientBrigbe-`**.
3. Framework Preset: **Vite** (detected automatically).
4. Click **Deploy**.
5. Once deployed, attach your custom domain under **Settings → Domains** for free!

### Deploy on Netlify:
1. Go to [netlify.com](https://netlify.com) and click **"Log in with GitHub"**.
2. Click **"Add new site" → "Import an existing project"**.
3. Select **`ClientBrigbe-`**.
4. Build command: `npm run build`, Publish directory: `dist`.
5. Click **Deploy Site**.
